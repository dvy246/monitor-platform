## 3. Caveats

- **Web Bluetooth / HCI Sandbox**: Browser JavaScript cannot read raw Bluetooth HCI packet headers directly. `WirelessLatencyEngine.ts` uses codec lookup models combined with setup configuration parameters, which is the mathematically correct web-native approach.
- **W3C Coalesced Pointer Events**: `TouchSamplingRateEngine.ts` unwraps `getCoalescedEvents()`. While supported in Chrome, Safari, and Firefox, in-app webviews inside certain social apps may clamp coalesced event arrays; the engine includes explicit fallback detection (`supportsCoalescedEvents: false`).
